- Proposed sequence: Phase 1 checkout safety and unserviceable-pincode enquiry; Phase 2 subscription price/date correctness; Phase 3 shortage/high-demand decision flow.
- Phase 1 is limited to checkout idempotency/recovery and unserviceable-pincode enquiry. Phase 2 remains subscription price/date correctness; Phase 3 remains shortage/high-demand decision flow.
- Recorded Website-aligned Phase 3 decisions: check requested-date threshold, then the Website Cart's one subsequent Saturday; if that later date also exceeds threshold, offer enquiry only.
